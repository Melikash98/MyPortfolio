01. Overview

PostGap is a modern social media application desigmed to help users share their moments, connect with friends and discover new communities. The app provides features like posts, stories, private messaging and community groups, giving users a simple and engaging way to stay connected.

I developed this project using native Android with Java, Firebase for real-time database and authentication, and Retrofit for API integration. The focus was on creating a smooth user experience with a clean UI and reliable performance.
